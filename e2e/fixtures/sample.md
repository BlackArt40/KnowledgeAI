# KnowledgeAI 产品手册

## 向量检索

KnowledgeAI 使用混合检索技术，将语义向量检索与 BM25 关键词检索通过 RRF 融合，
显著提升知识库问答的准确率。文档上传后会自动切片并向量化。

## 智能问答

用户可以直接向知识库提问，系统会流式生成带引用来源的回答。
回答基于检索到的文档内容，不编造信息。

## Agent 调研

Agent 功能支持多智能体编排：规划、检索、分析、撰写四个阶段协同完成调研报告。
报告支持 Markdown 格式导出与修订历史。

## 团队协作

团队支持四种角色：Owner、Admin、Editor、Viewer，权限覆盖知识库管理、
成员邀请、计费管理等能力。
