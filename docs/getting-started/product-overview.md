# KnowledgeAI 产品概述

## 产品定位

**产品名**：KnowledgeAI（AI知识助手SaaS）

**一句话介绍**：上传文档 → AI构建知识库 → 团队智能问答 → 自动生成调研报告

**整合的技术**：

| 技术领域  | 在产品中的体现                     |
| --------- | ---------------------------------- |
| 全栈开发  | Next.js前后端 + PostgreSQL + Redis |
| AI/ML应用 | RAG问答 + Agent调研 + 文档处理     |
| 云原生    | Docker部署 + K8s编排 + CI/CD       |
| 系统设计  | 多租户 + 微服务 + 消息队列         |
| 自动化    | GitHub Actions + 自动测试          |
| 业务理解  | 订阅计费 + 用量监控                |
| 安全合规  | 数据隔离 + GDPR合规                |

### 模块三：用户工作台（核心区域）

```
┌─────────────────────────────────────────────────────────┐
│  P7. 仪表盘（Dashboard）                                  │
│  ├── 本月问答次数 / 剩余额度                               │
│  ├── 知识库数量 / 文档总数                                 │
│  ├── 最近问答历史（5条）                                   │
│  ├── Agent任务状态（进行中/已完成）                         │
│  └── 用量图表（折线图，每日问答次数）                        │
├─────────────────────────────────────────────────────────┤
│  P8. 知识库管理（Knowledge Base）                          │
│  ├── 知识库列表（卡片视图）                                 │
│  │   ├── 知识库名称 / 文档数 / 最后更新时间                  │
│  │   └── 操作：编辑 / 删除 / 导出                          │
│  ├── 新建知识库按钮                                        │
│  └── 知识库详情页                                          │
│      ├── 文档列表（PDF/Word/Markdown/网页链接）             │
│      ├── 上传文档（拖拽上传 + 进度条）                      │
│      ├── 文档处理状态（解析中→切片中→向量化中→就绪）         │
│      └── 知识库设置（切片大小、Embedding模型选择）           │
├─────────────────────────────────────────────────────────┤
│  P9. 智能问答（Chat）                                      │
│  ├── 左侧：会话列表（新建/历史会话）                        │
│  ├── 中间：聊天界面                                        │
│  │   ├── 选择知识库下拉框                                  │
│  │   ├── 联网搜索开关（开启后提问同时检索 Web 来源）         │
│  │   ├── 消息气泡（用户/AI）                               │
│  │   ├── AI回答带引用来源（点击可跳转原文）                  │
│  │   ├── 流式输出（打字机效果）                             │
│  │   └── 快捷操作：复制 / 重新生成 / 反馈（👍👎）           │
│  └── 右侧：引用来源面板（展示检索到的文档片段）              │
├─────────────────────────────────────────────────────────┤
│  P10. Agent调研（Agent Research）                         │
│  ├── 任务输入框："帮我调研2026年AI就业市场"                  │
│  ├── 任务配置：                                            │
│  │   ├── 选择Agent组合（搜索Agent+分析Agent+写作Agent）     │
│  │   ├── 设置最大步骤数                                    │
│  │   └── 选择输出格式（报告/PPT大纲/思维导图）               │
│  ├── 任务执行过程可视化：                                   │
│  │   ├── 实时显示每个Agent的状态和工作内容                   │
│  │   ├── 步骤时间线（Plan→Search→Analyze→Write）           │
│  │   └── 中间结果预览                                      │
│  ├── 任务结果展示：                                        │
│  │   ├── 最终报告（Markdown渲染）                           │
│  │   ├── 引用来源列表                                      │
│  │   └── 导出（PDF/Markdown/分享链接）                     │
│  └── 历史任务列表                                          │
└─────────────────────────────────────────────────────────┘
```

**练习的技术**：
- RAG全流程（文档加载→切片→向量化→检索→生成）
- 自研多 Agent 编排（LangGraph 思路的零依赖 StateGraph 实现）
- 流式响应（Server-Sent Events）
- 文件上传处理（App Router 原生 FormData + 分片上传）
- 异步任务队列（BullMQ + Redis）

## 后续迭代新增页面（截至 2026-09-23）

原始规划的 25 个页面/能力已全部实现。此后迭代新增了以下 9 个页面路由，当前 `src/app` 共 **28 个页面路由**：

| 路由 | 说明 |
|------|------|
| `/developer` | 开发者门户：SDK 快速开始、Webhook 订阅管理、API 用量统计、第三方集成 |
| `/docs` | Swagger UI 交互式 API 文档（渲染 `/api/openapi.json`） |
| `/knowledge-base/[id]/graph` | 知识库知识图谱（实体/关系力导向探索） |
| `/admin/monitoring` | 可观测性监控面板（仅 Owner/Admin） |
| `/2fa-enroll` | 2FA 启用引导 |
| `/forgot-password` | 忘记密码 / 发起重置 |
| `/reset-password` | 重置密码 |
| `/r/[id]` | Agent 报告公开分享页 |
| `/share-doc/[token]` | 文档分享链接公开页 |

> 目录与模块全貌见[项目结构](project-structure.md)；服务边界与数据流见[总体架构](../architecture/overview.md)；设计令牌与组件见 [UI 设计体系](../architecture/design-system.md)。
