# 账号与邮箱安全

> 本页说明如何自助重置密码、完成注册邮箱验证，以及链接失效 / 收不到邮件时的处理方式。

## 忘记密码

1. 在登录页点击「忘记密码？」，输入注册邮箱并提交。
2. 若该邮箱已注册，会收到一封含**重置链接**的邮件（发件人见站点配置）。
3. 点击链接（30 分钟内有效，且只能使用一次），设置新密码（至少 8 位）。
4. 重置成功后**所有已登录设备会被强制退出**，请用新密码重新登录。

::: tip 安全说明
重置链接只发送给邮箱所有者；无论输入的邮箱是否注册，页面提示完全一致——不会向任何人泄露「某邮箱是否注册过」。
:::

## 邮箱验证

注册后系统会向你的邮箱发送一封**验证邮件**（24 小时内有效，单次使用）。点击「验证邮箱」按钮即完成验证。

- 验证是**可选的信任信号**：未验证不影响登录和正常使用。
- 邮件过期或误删：在验证结果页点击「重新发送」，或访问 `/verify-email` 输入邮箱再次获取。

## 链接失效 / 收不到邮件？

| 现象 | 原因与处理 |
| --- | --- |
| 提示「重置链接无效 / 已失效」 | 链接已使用或超过 30 分钟——回到「忘记密码」重新申请即可，新链接会使旧链接失效 |
| 提示「验证链接无效 / 已失效」 | 同上，24 小时有效期，重新发送即可 |
| 收不到邮件 | 检查垃圾邮件箱；确认邮箱拼写；稍等片刻（邮件经后台队列异步投递，失败会自动重试） |
| 页面提示演示模式 | 本地 / 演示部署未配置邮件服务，重置链接不会真正发出（见下） |

## 部署方配置（管理员）

邮件投递使用 Resend 云端 API，需要设置：

```bash
RESEND_API_KEY="re_xxx"
EMAIL_FROM="KnowledgeAI <noreply@yourdomain.com>"
# 公网访问地址——邮件里的链接 base，反代 / 内网部署后必须显式设置
NEXT_PUBLIC_APP_URL="https://your-domain.com"
```

未配置邮件服务时应用运行在演示模式：生产环境下重置 / 验证请求返回统一响应（不泄露链接），本地开发则直接在响应中返回演示链接便于联调。相关限流：每个邮箱每分钟最多触发 3 封（`RATE_LIMIT_AUTH_EMAIL_PER_MIN` 可调）。
